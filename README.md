# SKILL BRIDGE LMS Mockups Viewer

A streamlined viewer for exploring and visualizing UI mockups for the SKILL BRIDGE Learning Management System. This interactive viewer allows users to browse, search, and examine mockups from different perspectives.

## Features

- **Multiple Views**: Grid, List, and Category-based organization
- **Search Functionality**: Find mockups by name, description, category, or tags
- **Detailed Mockup Information**: View comprehensive details about each mockup
- **GitHub Integration**: Direct links to view source code on GitHub
- **Responsive Design**: Works well on different screen sizes

## About SKILL BRIDGE

SKILL BRIDGE is a next-generation learning platform addressing key gaps in traditional Learning Management Systems:

- Emphasis on skill development rather than content delivery
- Personalized learning paths based on individual needs
- Project-based verification of skills
- Real-world application focus
- AI-powered personalization
- Career connection and progression tracking

## Available Mockups

The viewer provides access to 18 different mockups across various categories:

- **AI Features**: AI-powered personalization and learning assistance
- **Analytics & Feedback**: Comprehensive dashboards and feedback systems
- **Assessment & Credentials**: Skill verification and portfolio systems
- **Career Development**: Career-oriented learning pathways
- **Content Delivery**: Interactive and adaptive learning experiences
- **Core Platform**: Main platform dashboards and navigation
- **Experiential Learning**: Immersive and project-based approaches
- **Knowledge Management**: Concept mapping and application
- **Personalization**: Customized learning journeys
- **Progress Tracking**: Skill and domain progression tracking
- **Social Learning**: Community and collaborative learning features
- **Synchronous Learning**: Live session facilitation
- **User Experience**: Onboarding and assessment

## Getting Started

1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm start` to launch the development server
4. Open your browser to http://localhost:3000

## Technology Stack

- React.js
- Tailwind CSS
- Lucide React icons
